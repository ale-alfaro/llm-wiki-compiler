The term **“cell”** is typically used to refer to the individual data elements within
properties and can thus be thought of as a single unit of data in a property

| Zephyr type | DTSpec equivalent | Example |
| --- | --- | --- |
| `boolean` | `property with no value` | `interrupt-controller;` |
| `string` | `string` | `status = "disabled";` |
| `array` | `32-bit integer cells` | `reg = <0x40002000 0x1000>;` |
| `int` | `A single 32-bit integer cell` | `current-speed = <115200>;` |
| `64-bit integer` | `32-bit integer cells` | `value = <0xBAADF00D 0xDEADBEEF>;` |
| `uint8-array` | `bytestring` | `mac-address = [ DE AD BE EF 12 34 ];` |
| `string-array` | `stringlist` | `compatible = "nordic,nrf-egu", "nordic,nrf-swi";` |
| `compound` | “comma-separated components” | `foo = <1 2>, [3, 4], "five"` |

```dts title:example_types
/ {
  props {
    existent-boolean;
    int = <1>;
    array = <1 2 3>;
    uint8-array = [ 12 34 ];
    string = "foo";
    string-array = "foo", "bar", "baz";
  };
};
```

#### Phandles

| Zephyr type | DTSpec equivalent | Example |
| --- | --- | --- |
| `path` | `32-bit integer cells` | `zephyr,console = &uart0;` |
| `phandle` | `phandle` | `pinctrl-0 = <&uart0_default>;` |
| `phandles` | `32-bit integer cells` | `cpu-power-states = <&idle &suspend>;` |
| `phandle-array` | `32-bit integer cells` | `gpios = <&gpio0 13 GPIO_ACTIVE_LOW>;` |

```c title:phandle_example
/ { 
 //phandle is a 32 bit integer that is the reference to a node.
 //Can be specified explicitly
 label_a: node_a {
     phandle = < 0xc0ffee >;
 };
 // OR not. in this case the phandle will be autogenerated
 label_a: node_a { /* Empty. */ }; 

 node_refs {
  phandle-by-path = <&{/node_a}>; 
  phandle-by-label = <&label_a>; 
 }; 
};
```

#### /Aliases and /chosen

Simply put, `/aliases` are just yet another way to get the full path to nodes *in your
application*. In the
[previous section](https://interrupt.memfault.com/blog/practical_zephyr_dt#path-phandles-and-phandle-array),
we’ve learned that outside of `<` and `>` a reference to another node is expanded to
that node’s full path.
Thus, for any alias, we can specify its **value of type `path`** using references or a
plain string, as shown in the example below:

```dts
/ {
  aliases {
    alias-by-label = &label_a;
    alias-by-path = &{/node_a};
    alias-as-string = "/node_a";
  };
  label_a: node_a {
    /* Empty. */
  };
};
```

The `/chosen` node does not represent a real device in the system but describes
parameters chosen or specified by the system firmware at run time.
It shall be a child of the root node.

```dts
/ {
  chosen {
    zephyr,console = &uart0;
    zephyr,shell-uart = &uart0;
    zephyr,uart-mcumgr = &uart0;
    zephyr,bt-mon-uart = &uart0;
    zephyr,bt-c2h-uart = &uart0;
    zephyr,sram = &sram0;
    zephyr,flash = &flash0;
    zephyr,code-partition = &slot0_partition;
    zephyr,ieee802154 = &ieee802154;
  };
};
```
