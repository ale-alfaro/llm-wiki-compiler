# Overview of NFC Charging (as it relates to Sibel's designs)
## Purpose

The purpose of this feature is to:
1. Have wireless charging for the device so it can be completely encapsulated and have no need for a receptacle connector such as USB-C receptacle
2. Have NFC communication for the Tap-to-Pair feature with the patient monitor and ease the use of the device
